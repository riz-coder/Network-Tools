# NETWORK-TOOLS

Single-service Django app for network automation tools.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python start_network_tools.py
```

Open:

```text
http://127.0.0.1:8501
```

Only one local service is required. The old Streamlit launcher/iframe setup is no longer used.
